# Memory index

Load selectively. Records are historical claims that may need revalidation.
See [the memory protocol](../kestrel/MEMORY_PROTOCOL.md) for format and lifecycle.

| Scope | Use |
| --- | --- |
| [Shared knowledge](shared/INDEX.md) | Cross-project decisions and transferable lessons |
| [Project catalog](projects/INDEX.md) | Find a project by its owner/repository identity |
| [Agent catalog](agents/INDEX.md) | Optional continuity for an established agent identity |
| [Skill catalog](../skills/INDEX.md) | Recall and save procedures |

Use the catalogs first, then targeted text search if needed. A missing entry is unknown
context; it is not evidence that a project has no history or that an operation is authorized.
